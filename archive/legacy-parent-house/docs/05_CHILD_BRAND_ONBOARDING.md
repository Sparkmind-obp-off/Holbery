# 05 — CHILD BRAND ONBOARDING

## 1. Purpose
This document is the gate for introducing a new brand into the HOLBERY portfolio.

## 2. Required brief
Every child-brand proposal must include:
- working name
- target customer
- problem / job to be done
- value proposition
- initial offer
- future expansion path
- business model
- distribution plan
- parent relationship
- reason for separate brand identity
- preliminary naming clearance

## 3. Gate A — Strategic fit
Pass only if the brand has a clear role inside the portfolio.

## 4. Gate B — Brand distinction
The brand must be meaningfully distinguishable from other HOLBERY brands.

## 5. Gate C — Commercial viability
There must be a realistic path to demand, revenue, or strategic value.

## 6. Gate D — Clearance
The name must undergo exact-name, near-name, company, trademark, domain, social, linguistic, and adversarial checks before being treated as launch-ready.

## 7. Gate E — Operating readiness
Minimum requirements:
- product definition
- price / unit economics
- fulfillment path
- customer support owner
- analytics baseline
- channel ownership

## 8. Approval status
Use only:
- `IDEA`
- `INCUBATING`
- `PROVISIONAL`
- `APPROVED`
- `LIVE`
- `PAUSED`
- `RETIRED`

## 9. No automatic inheritance
A child brand does not automatically inherit the parent identity, customer promise, pricing, or audience. It inherits governance and access to shared infrastructure.
