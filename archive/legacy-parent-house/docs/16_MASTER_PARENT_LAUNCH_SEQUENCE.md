# 16 — MASTER PARENT LAUNCH SEQUENCE

## Stage 1 — Parent identity
Status: strategic lock.

Deliver:
- HOLBERY name system
- parent wordmark
- core message
- parent domain strategy
- social identity strategy
- corporate narrative

## Stage 2 — Parent proof
Before adding many brands, give HOLBERY something real to own:
- one working child brand;
- one real shared capability;
- one visible portfolio page;
- one canonical product / commerce registry.

## Stage 3 — First child
Choose a child with:
- a clear market
- a clear offer
- realistic distribution
- measurable economics

Do not launch five child brands simultaneously.

## Stage 4 — Shared services
Centralize only what creates leverage:
- catalog
- transaction model
- analytics
- reporting
- selected finance / operations
- selected technology

Keep category-specific decisions close to the child brand.

## Stage 5 — Portfolio cadence
Run a monthly or quarterly parent review:
- revenue
- margin
- growth
- retention
- channel mix
- product velocity
- operating burden
- strategic fit

## Stage 6 — Expansion
Add brands only when:
- there is a distinct market opportunity;
- the new brand benefits from being separate;
- shared infrastructure can reduce cost;
- the parent has the capacity to govern it.

## Stage 7 — Group maturity
When multiple brands are producing meaningful value, HOLBERY can evolve from:
**brand house → operating house → commerce group → multi-brand group**

## Minimum viable parent
HOLBERY does not need a huge headquarters, complex org chart, or many subsidiaries to become a legitimate parent.

The minimum is:
1. a clear parent identity;
2. a governed child-brand model;
3. a shared operating capability;
4. a documented ownership structure;
5. a portfolio decision process;
6. at least one real child business.

## North-star
**Build the parent before the portfolio gets complicated, but build shared infrastructure only when it creates leverage.**
