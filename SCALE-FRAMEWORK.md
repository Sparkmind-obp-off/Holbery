# HOLBERY — Evidence-led Scale Framework

2026-10-06 | Ready-to-review framework; actual scale PENDING.

## Gates

G1 utility: real external use and result comprehension beyond engineering fixtures. G2 return/recommendation: repeated useful work and feedback; short-tab repeats are limited signals, not retained customers. G3 commercial: actual external paid commitments + server-verified transactions + controlled delivery. G4 outcome: product used to create observable value without unsupported attribution. G5 repeatability: cohorts, contribution, support burden, quality and capacity stable. G6 portfolio: second problem/vertical supports reuse without harming existing obligations.

## Scale actions

At each gate, choose one bounded step: improve discovery, fix friction, clarify result assumptions, interview targeted users, improve existing offer/delivery, or test one new vertical. Do not build additional tools solely from feature enthusiasm. No paid traffic, marketplaces, giant SaaS or analytics warehouse now.

## Portfolio review

Monthly: owner, evidence level, outcome/sample/window, economics/support, rights, failure risks, next hypothesis, budget/capacity, return/retirement triggers. Keep approved commitments/service policies. Reuse existing D1/R2/commerce rather than duplicate infrastructure. Real provider/server records remain payment truth.

## Stop / rollback

Stop expansion for negative contribution, rising support/defects, missing ownership/rights, privacy harm, or no useful outcome. Roll back deployment/process without resetting customer/order history. Resolve contractual obligations before retirement/exit. A framework marked IMPLEMENTED is not a claim of SCALE lifecycle.
