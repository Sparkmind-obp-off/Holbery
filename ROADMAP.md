# HOLBERY — Master Roadmap

**Version:** 2.0  
**Status:** CANONICAL ACTIVE ROADMAP  
**Parent layer:** [HOLBERY-LIBRARY.md](HOLBERY-LIBRARY.md)

> This document is the active roadmap. Historical execution reports belong in the archive and must not be mixed with current planning.

## Master objective

Build HOLBERY from a documented parent-brand foundation into a **real, evidence-driven parent ecosystem** capable of repeatedly discovering, validating, building, operating, productizing, and—only when justified—graduating independent businesses or child brands.

The goal is not to look large.

The goal is to become **structurally real, commercially useful, operationally repeatable, and evidence-backed**.

# 11. CHILD-BRAND / VENTURE GRADUATION

### Objective
Allow proven units to become independent where independence creates strategic value.

### Graduation criteria

A unit should normally demonstrate:

- distinct customer/audience;
- distinct problem/promise;
- meaningful market separation;
- independent economic potential;
- accountable owner/operator;
- repeatable operating model;
- clear parent-brand limitation;
- clean rights/IP separation;
- credible naming/domain/handle position;
- strategic reason to exist independently.

### Gate

If the separation case is weak:

**KEEP IT HOLBERY-NATIVE.**

### Status
**GOVERNANCE DEFINED / NO CHILD BRAND REQUIRED NOW**

# HOLBERY MATURITY MODEL

HOLBERY should be judged across six dimensions:

| Dimension | Question |
|---|---|
| Identity | Is HOLBERY clearly defined? |
| Architecture | Is the portfolio structurally organized? |
| Capability | Can the system repeatedly build/operate useful things? |
| Evidence | Are real users and outcomes present? |
| Economics | Is there real revenue/margin/repeatability? |
| Portfolio | Are multiple proven assets/ventures governed coherently? |

A phase is **document-complete** when its framework exists.

A phase is **operationally mature** only when the framework works in reality.

A phase is **commercially proven** only when external evidence supports it.

These are deliberately different states.

# NON-NEGOTIABLE RULES

1. Never fabricate customers, revenue, validation, ownership, or legal clearance.
2. Never create child brands for cosmetic portfolio size.
3. Search the Library before creating new work.
4. Reuse before rebuilding.
5. Keep experiments clearly labelled.
6. Keep private projects outside the public parent library unless explicitly authorized.
7. Do not let historical documents override canonical current decisions.
8. Every material asset needs ownership/right/status tracking.
9. Every graduation requires evidence.
10. When evidence is insufficient, use **HOLD**, not invention.

---

# DEFINITION OF “HOLBERY IS REAL”

HOLBERY becomes meaningfully real as a master parent ecosystem when it can demonstrate:

- a coherent parent identity;
- a functioning master library;
- reusable operating capabilities;
- at least one real validated offer;
- real customer/operator evidence;
- real commercial transactions or equivalent external proof;
- repeatable operating processes;
- governed assets and rights;
- a second validated use of the operating pattern;
- and eventually, selective independent portfolio units where justified.

**The destination is not the number of brands.  
The destination is the ability to repeatedly create and operate valuable businesses with clarity and proof.**
