# HOLBERY Commerce Roadmap

C0 — Make HOLBERY sellable: catalog, storefront, D1, child ownership.
C1 — Make HOLBERY transactional: cart, checkout, order, idempotency.
C2 — Make HOLBERY payable: Duitku adapter, callback verification, reconciliation.
C3 — Make HOLBERY operable: order admin, fulfillment, inventory, customer records.
C4 — Make HOLBERY distributable: portfolio marketplace, child storefronts, canonical URLs, channel registry.
C5 — Make HOLBERY extensible: promotions, refunds, partner attribution, external channels.
C6 — Optional true marketplace: seller onboarding, seller contracts, commissions, split settlement/payouts.

C0–C4 is the fastest route to a useful HOLBERY commerce system without prematurely building a full multi-seller financial stack.
