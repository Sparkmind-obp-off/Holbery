# HOLBERY — Naming System

Phase 3 | [Governance](BRAND-GOVERNANCE.md). HOLBERY tetap nama induk.

## Konvensi

| Obyek | Aturan | Contoh status jujur |
|---|---|---|
| Master | HOLBERY, uppercase wordmark; satu parent | HOLBERY |
| Parent-native system | HOLBERY + functional descriptor bila membantu authority | HOLBERY Barber Business System, EXPERIMENT |
| Produk kecil | Functional outcome/format, bukan invented child | Daily Close Kit |
| Endorsed child | Child utama; parent signal sesuai hubungan/hak yang verified | “Built within HOLBERY” hanya jika benar |
| Independent child | Nama distinct bila gate brand separation lulus | Kandidat, bukan otomatis owned company |
| Internal project | Pertahankan existing valid name; visibility private; jangan publikasi data/IP | Bozq One System tetap private/internal |
| Experiment | exp-<vertical>-<problem>-<sequence>; timebox dan owner | exp-barber-daily-close-001 |
| Campaign | <offer>-<channel>-<YYYYMM>; tidak punya parent baru | daily-close-discovery-202610 |
| Domain | holberry.biz induk; child domain hanya jika strategic value/rights | Availability dan ownership dicek terpisah |
| Social | Utamakan exact HOLBERY atau holbery + descriptor relevan jika tidak tersedia | @holbery adalah preferred, UNVERIFIED |
| Repository | holbery tetap repo existing; child holbery-<function> hanya bila perlu | Sparkmind-obp-off/Holbery |

Ejaan domain induk sengaja holberry.biz (dua r); merek tetap HOLBERY (satu r). Jangan mengoreksi domain menjadi varian lain. Domain lama hanya sejarah; jangan membuat redirect tanpa kendali sah.

## Screening sequence

Descriptive brief → exact/near/phonetic/linguistic screening → registry/domain/social checks → rights/legal review sesuai aktivitas/jurisdiksi → approval → publish. Nama anak dapat disaring; nama master tidak dieksplorasi ulang kecuali konflik material.

Trademark classes mengikuti aktivitas nyata, bukan semua bucket sekaligus. Search web tidak membuktikan legal clearance. Domain available tidak membuktikan non-infringement. Similar spellings/linguistic issues dicatat dengan source/time/limitations.

## Collision rules

Jika nama/domain/repo bertabrakan: HOLD, dokumentasikan materiality, jangan mengambil alih asset orang lain. Untuk infra Pages, suffix numeric boleh; nama teknis tidak menjadi child brand. Jangan rename internal project atau membuat logo child hanya demi konsistensi.

## Decision examples

Barber workflow untuk operator lokal dengan parent fit: HOLBERY directly. Template kas sekali unduh tanpa alasan independen: nama produk deskriptif. Consumer business dengan audience/economics berbeda: child review setelah rights gate. Proposed brand tanpa pemilik IP jelas: HOLD. Generative AI tool boleh ada di SYSTEMS; jangan menjadikan induk generic AI brand.

Acceptance dilakukan dengan fungsi namingDecision dan unit tests: default parent, descriptive alternative, rights gate dan independent review. Keputusan fungsi adalah rekomendasi, bukan legal/brand approval otomatis.
