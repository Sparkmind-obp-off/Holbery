# 04 — BRAND IDENTITY SYSTEM

## 1. Core expression
### HOLBERY
The wordmark must be able to stand alone without an icon.

## 2. Visual character
Target:
- refined typography
- generous whitespace
- restrained layouts
- clear hierarchy
- editorial confidence
- warm neutrality
- premium through proportion

Avoid:
- neon gradients
- crypto visual language
- excessive glassmorphism
- ornamental luxury patterns
- noisy badges
- overly futuristic UI

## 3. Wordmark direction
Preferred direction:
- clean humanist or refined grotesk sans-serif
- medium-to-regular weight
- disciplined letter spacing
- balanced kerning
- uppercase or title-case depending on context

Recommended primary presentation:

`HOLBERY`

Secondary corporate expression:

`HOLBERY House`

## 4. Color philosophy
Use a restrained neutral palette as the parent default. Child brands may diverge where category strategy requires it.

Parent UI should feel calm first, premium second, expressive third.

## 5. Photography / imagery
Prefer:
- real materials
- human context
- subtle texture
- product detail
- natural light
- quiet composition

Avoid generic stock imagery whenever possible.

## 6. Voice
HOLBERY voice is:
- direct
- clear
- warm
- composed
- intelligent without jargon
- confident without hype

Use short sentences.

Do not overclaim.

## 7. Copy test
Good:
“Built with care. Designed to last.”

Weak:
“The revolutionary next-generation AI-powered ecosystem transforming everything.”

## 8. Child brand relationship
HOLBERY should provide a stable parent tone while allowing child brands to develop their own customer-facing personality.
