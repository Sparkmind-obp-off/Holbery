# 14 — BRAND RELATIONSHIP SYSTEM

## 1. Architecture type

HOLBERY uses a **Parent-led Hybrid House**.

It is deliberately not:
- a pure Branded House where every offer is called HOLBERY;
- a pure invisible holding company where nobody sees the parent;
- a loose collection of unrelated brands with no shared operating truth.

## 2. Relationship modes

### Mode 1 — Independent
The child brand stands alone in customer-facing markets.

Use when:
- category identity matters strongly;
- the child needs a distinct audience relationship;
- parent visibility adds little customer value.

### Mode 2 — Endorsed
The child brand owns the customer relationship but carries a light parent signal.

Example:
**Brand Name**
*A HOLBERY company*

Use when parent trust or operational credibility helps.

### Mode 3 — Parent-native
The offer is intentionally part of the HOLBERY identity.

Use for:
- group-level services
- shared infrastructure
- portfolio intelligence
- corporate partnerships
- parent-level commerce capabilities

## 3. Visibility matrix

| Surface | HOLBERY | Child Brand |
|---|---:|---:|
| Parent website | Primary | Secondary |
| Child website | Endorser / footer | Primary |
| Product packaging | Optional | Primary |
| Marketplace listing | Usually secondary | Primary |
| Corporate deck | Primary | Supporting |
| Recruitment | Primary | Supporting |
| Investor / partner | Primary | Supporting |
| Social campaign | Context-dependent | Usually primary |

## 4. Non-negotiable
Do not put HOLBERY in front of every child brand name just to prove ownership.

Bad architecture:
**HOLBERY Kestora**
**HOLBERY Brand B**
**HOLBERY Product C**

Preferred:
**KESTORA**
*A HOLBERY company*

This preserves child-brand equity while maintaining portfolio ownership.

## 5. Brand equity rule
The parent builds:
- trust in ownership
- quality of systems
- portfolio credibility
- partner confidence

The child builds:
- category authority
- customer affinity
- product preference
- community

This separation allows both layers to become stronger.

## 6. Exit / sale rule
If a child brand is sold, the child may leave the portfolio.

HOLBERY remains intact.

If shared infrastructure is transferred, contracts and IP must be separated deliberately.
