# HOLBERY — Commerce-backed Revenue Model

2026-10-06 | Utility first; economics still matter. No claimed revenue or sale from event counts.

## Model

Free utility lowers discovery friction and creates useful repeat interactions. Organic content/search distribute answers. Existing paid packaged system captures value when a customer needs operating support beyond a calculation. No acquisition spend, new subscription or paid-product inventory added in this run.

## Economics

Contribution = collected/recognized revenue − refunds − provider fees − variable fulfillment/support cost − attributed acquisition cost. Margin = contribution / revenue only when denominator positive. CAC = attributed acquisition cost / new paying customers; zero payers means UNKNOWN, not zero CAC. Recurring revenue/retention cannot be inferred from one-time kit purchases or short-lived tool sessions.

BRS public price anchorRp99.000 is current catalog data, not price-demand validation. Illustrative cost model (NOT ACTUAL): fee3% Rp2.970, support30min × Rp50.000/hour Rp25.000, delivery allocationRp5.000 → contributionRp66.030 before tax/fixed overhead/refunds/acquisition. If support90min, illustrative contribution falls toRp16.030. Replace assumptions with actual measured cost before scaling.

## Revenue authority

Only verified provider notification + server inquiry persisted in commerce/payment records can establish paid status. Field events, frontend callbacks, visits, trial uses and checkout intent are not revenue. No anonymous session identifier is joined to customer/payment identity for this utility ledger. Existing administrative commerce evidence remains the source for real orders and fulfillment.

## Monetization trigger

Proceed only when real usage/problem/value/demand justify the existing offer, and real external transactions/delivery/outcomes begin to support repeatability. No deadline to sell after30 days. Preserve free calculators/templates; paid means repeated operating value or licensed package, not blocking an answer behind signup.
